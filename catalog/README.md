# Reproducible Nevermined Catalog outcomes

These examples show the tutorial, runnable code, redacted representative output, and observed cost for three distinct paid builder outcomes. Each runner creates a short, capped delegation and checks its Router payments. Listed Catalog prices are estimates; the observed amounts below come from bounded Live runs on 2026-09-15. Bring your own Nevermined API key and real balance, review the prerequisites in each tutorial, and keep raw `out/` responses private.
